### Prerequisites

Download and install [Java Runtime Environment 8 Update 361](https://www.java.com/en/download/)

Check your JRE installation with command `java --version`

### Portable

Download and extract latest release. Launch the main GUI by the following command:

```
java --class-path unimod-renderware.jar;lib/* com.openitvn.gtavc.gui.Startup
```

Or just to double click on `GTAViewer.bat` if you are running on Windows.
